# Being Balanced Consultancy Ventures

This is a mental health and wellness consultancy website providing counseling services, support groups, and professional development programs. The website serves as a digital storefront and resource hub for mental health support, led by Dr. Teena Augustine Joseph.

## Project Structure
- **Pages**: Static HTML files for various sections like Home, About, Services, Resources, Podcasts, and Contact.
- **Assets**: 
  - `assets/css/`: Contains styling for the project.
  - `assets/js/`: Contains interactivity scripts and libraries.
  - `assets/fonts/` & `assets/misc/`: Other frontend assets.
- **Images**: Local assets stored in the `images/` directory.

## Features
- Comprehensive directory of mental health resources with interactive filtering (`resources.html`).
- Information on One-on-One Counseling, Support Groups, Group Therapy, and Employee Assistance Programs.
- Integrated testimonial carousels to showcase client feedback.
